# Карточка модели

Язык карточки — русский. Ключи JSON в каталоге модели остаются английскими.

`weights.pth` — веса для инференса. `training_checkpoint.ckpt` копируется только если библиотека записала checkpoint. Отсутствие файла допустимо и не является успешной точкой возобновления. Загрузка checkpoint при сборке карточки не проверяется.

Официальные веса COCO в этот каталог как обученная модель не кладутся.

## Область применения

Для чего собран bundle: детекция четырёх классов на видео экскавации либо диагностика overfit.

Диагностика с `metric_role` `diagnostic_overfit` не является карточкой качества и не описывает результат на test.

Карточка не подтверждает разгрузку и не заменяет отдельную оценку на отложенном test.

## Ракурс

`view_id`: идентификатор ракурса, на котором собраны кадры. Если ракурс не записан, значение «не рассчитано».

## Тип техники

`equipment_family`: семейство техники. Если оно не записано, значение «не рассчитано».

## Разбиение

Независимость разбиения принимает значение `episode_split` или `same_scene`.

`episode_split` — разные эпизоды разведены по train, validation и test.

`same_scene` — проверка той же сцены, не переносимость на другой ракурс.

Если независимость не прочитана из split manifest, значение «не рассчитано». `episode_split` не подставляется наугад.

## Исключённые условия

Условия, которых не было в обучении или которые выведены из оценки. Если список не записан, значение «не рассчитано».

## Метрики

Числа копируются из `validation_metrics.json`. Пустое значение пишется как «не рассчитано», не как 0.

- box mAP50:95
- AP ковша
- История метрик

Если `metrics_history.csv` содержит только заголовок, история — «не рассчитано». Строки журнала не заменяются нулём.

Если `metric_role` равен `diagnostic_overfit`, числа диагностические. Они не являются качеством на test.

## Другие камеры

Если другой камеры не было в проверке, карточка содержит строку:

Другая камера не проверялась.

Проверка на другом фрагменте того же ролика остаётся `same_scene` и этой строкой не отменяется.

## Веса и resume

`weights.pth` используется для инференса.

`training_checkpoint.ckpt` — checkpoint библиотеки для resume, и только когда он был записан. Отсутствие файла не является успешной точкой возобновления.
